Hosted privacy

GitHub sign-in

The dashboard uses a session cookie. The hosted service keeps the GitHub sign-in token in server memory for up to an hour for that dashboard session. Sign out to end the session. The CLI stores its GitHub credentials and encryption identity in your operating system’s credential store.

Repository and access data

The GitHub App accesses account, repository, team, and permission information to check access. The service stores repository and account identifiers, approved policies, relevant public keys, group keys encrypted for their recipients, and records of security events.

The merge guard reads relevant Git content from enrolled repositories to verify compliance with the approved policy. If someone pushes plaintext, it may already be in GitHub history by the time the check runs. Normal key distribution uses encrypted keys. Your local private key decrypts them.

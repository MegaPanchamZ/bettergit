# Security policy

[Report a vulnerability privately on GitHub](https://github.com/MegaPanchamZ/bettergit/security/advisories/new). This covers hosted Better Git and the open-source CLI, control plane, and browser extension. Include the affected version or commit, the expected access boundary, and the observed impact. Use dummy data and omit credentials, private keys, and private repository contents. Use [GitHub Issues](https://github.com/MegaPanchamZ/bettergit/issues) for general bugs and questions.

See the [security model](docs/security-model.md) and [release gates](docs/validation.md#production-release-gates) for the public pilot.

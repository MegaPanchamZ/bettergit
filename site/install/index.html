Install Better Git

Download the latest pilot build for macOS or Linux (Intel or ARM64), or for 64-bit Windows.

View CLI releases

Each release lists its platform archives, shell and PowerShell installers, and SHA-256 checksums.

Build from source

Install Git and stable Rust. See the Quickstart for Linux build dependencies and keychain setup.

Source install
git clone https://github.com/MegaPanchamZ/bettergit.git
cd bettergit
cargo install --locked --path .
bettergit --version

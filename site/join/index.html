Join a private branch

  1. Install Git and download Better Git for your operating system.
  2. Run bettergit login and sign in with the GitHub account your workspace administrator added.
  3. Use your GitHub HTTPS credential manager. If you use GitHub CLI, run gh auth login --git-protocol https and gh auth setup-git.
  4. Run this in an empty directory or in an existing clean checkout of the parent repository.

Open the full link shared by your workspace administrator.

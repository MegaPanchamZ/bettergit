Try Better Git on a test repo

See a dummy config value stay readable on your machine and turn into ciphertext in Git. The local demo needs no GitHub account.

Install the CLI

Encrypt a value locally

With Git, Better Git, and your OS keychain available, run this in a macOS or Linux terminal, or Git Bash on Windows. It creates a new bettergit-demo directory.

Local demo commands
(
set -e
mkdir bettergit-demo
cd bettergit-demo
git init -b main
cat > .access.yml <<'YAML'
version: 1
org: demo
rules:
  - path: .env.demo
    mode: value
    allow: [github-team:infra]
YAML
printf '%s\n' 'DEMO_TOKEN=sample-only' > .env.demo
bettergit init
signing_key=$(bettergit group-signing-key github-team:infra)
printf '    signing_key: %s\n' "$signing_key" >> .access.yml
bettergit init
git add -- .access.yml .gitattributes .env.demo
bettergit check-staged --json
git show :.env.demo
)

The check should report one verified file and no issues. The last line starts with DEMO_TOKEN=ENC[v2:. Open bettergit-demo/.env.demo locally to see the original value.
